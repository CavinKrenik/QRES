# QRES v15.0.0 "Privacy"

**Release Date:** January 8, 2026

---

## Overview

v15.0.0 completes **Phase 3: Privacy** of the QRES security roadmap. This release adds provable privacy guarantees to federated swarms.

---

## Key Features

### Differential Privacy (`privacy.rs`)
- Gaussian mechanism with configurable ε/δ
- Box-Muller fallback for no_std/WASM

### Secure Aggregation (`secure_agg.rs`)
- Pairwise masking via X25519 + ChaCha20
- Zero-sum masks cancel upon aggregation

### Zero-Knowledge Proofs (`zk_proofs.rs`)
- Pedersen Commitments on EdwardsPoint
- Proof of Norm for poisoning defense
