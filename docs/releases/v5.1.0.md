# QRES v5.1.0: Telepathy & Studio

> **Stable core release with Telepathy Engine and GUI.**

Introduction of the Neural-Symbolic "Telepathy" architecture and the first release of QRES Studio.

## 🚀 Highlights
- **feat(core):** "Living Brain" predictor selection (Linear/Simple/Graph).
- **feat(archive):** `.qrar` format with CDC deduplication.
- **feat(gui):** QRES Studio (Tauri v1) for drag-and-drop compression.
- **feat(p2p):** Native Rust Swarm (libp2p) replaces Python Hive.

## ⚠️ Breaking Changes
- CLI renamed from `qres create` to `qres archive`.
- New `.qrar` file extension.
