# QRES v7.0.0-beta: Quantum Foundations

> **Beta preview of quantum-inspired intelligence with multi-modal RL gains.**

This release marks the completion of Phases 0-2, introducing the **QuantumEncoder** (simulated via QuTiP) and **Multi-Modal RL** (PPO Agent).

## 🚀 Highlights
- **feat(quantum):** Tensor Network compression with QuTiP noise simulation (>40% efficiency gains).
- **feat(ai):** Adaptive PPO Agent (Gymnasium) for autonomous predictor selection.
- **feat(multi-modal):** NetworkX + CLIP integration for processing mixed text/image graphs.
- **fix(core):** Resolved CI import errors and path resolutions.

## ⚠️ Breaking Changes
- **New Dependencies:** `torch`, `qutip`, `gymnasium`, `networkx`.
- **API:** `QuantumEncoder` replaces legacy `SpectralPredictor` for complex signals.

## 📦 Assets
- `qres_quantum_cli.py` (Hybrid Quantum/Classical CLI)
- Pre-trained RL Models (`qres_rl_weights.pt`)

## 🛠 Upgrade Guide
Validation scripts provided:
```bash
python verify_fidelity.py --mode quantum
```
