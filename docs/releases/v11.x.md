# QRES v11.0.0 - v11.2.0: The Portable Era

> **Cross-Platform. Cross-Architecture. Cross-Browser.**

The v11.x series focused on portability and expanding QRES to run on any architecture and in any environment.

---

## v11.2.0 - Federated Swarms

### Added
- **Federated Swarms:** Zero-bandwidth weight synchronization via PRNG seeds
- **Federated Dreaming:** Idle-time synthetic sample generation for privacy-preserving learning
- **Swarm Metrics:** Detailed synchronization benchmarks

---

## v11.1.0 - Portable SIMD

### Added
- **Portable SIMD:** Full migration from x86-only intrinsics to `wide` crate
- **Cross-Platform:** Compiles for ARM NEON, x86 AVX, and WASM SIMD
- **Diverse IoT Benchmarks:** New test datasets (trending, anomaly, correlated, mixed)

### Benchmarks
| Dataset | Size | Ratio | Pattern |
|---------|------|-------|---------|
| iot_trending.dat | 15MB | 0.489 | Sine + drift |
| iot_anomaly.dat | 15MB | 0.735 | Stable + spikes |
| iot_correlated.dat | 15MB | 0.846 | Multi-sensor |
| iot_mixed.dat | 15MB | 0.473 | Alternating |

---

## v11.0.0 - Browser Persistence

### Added
- **Fast Sigmoid:** Optimized activation function for embedded
- **Browser Persistence:** IndexedDB integration for client-side model storage
- **Studio Improvements:** Enhanced UI responsiveness and error handling
