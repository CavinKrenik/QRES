# QRES v10.1.0 Release Notes: "The Clean Slate"

**Date:** 2026-01-05
**Tag:** `v10.1.0`

## 🔒 Security Advisory
This release introduces a **breaking security change**. The QRES Daemon API now binds to `127.0.0.1` by default. Previous versions bound to `0.0.0.0`. If you rely on external access to the API (e.g., from a different machine in a cluster), you must now start the daemon with the `QRES_PUBLIC` environment variable set.

## 📦 Persistence Migration
The `WorldStateManager` has migrated from Python's `pickle` format to **JSON**.
- **Why?** `pickle` is insecure and allows arbitrary code execution if a malicious state file is loaded. JSON is safe and portable.
- **Migration:** Existing `.db` files created with pickle in v10.0 are **not compatible** with v10.1. You must start a fresh world state or use the legacy conversion script (if available).

## 📝 Structured Logging
Logs are now output in JSON format:
```json
{"timestamp": "2026-01-05T10:00:00Z", "level": "INFO", "target": "qres_daemon", "message": "Daemon started on 127.0.0.1:8080"}
```
This enables integration with log aggregators like ELK, Datadog, or CloudWatch.

- **macOS (ARM64):** Sequoia 15.1
- **Python:** 3.10, 3.11, 3.12
