# QRES v6.0.0-alpha: Singularity Engine

> **Experimental alpha introducing the Semantic Predictor.**

First preview of the "Singularity" architecture, featuring LLM-driven prediction and GPU acceleration.

## 🚀 Highlights
- **feat(ai):** LLM Semantic Predictor (CodeLlama integration) for text/code.
- **feat(gpu):** `wgpu` compute pipeline for batch mixing.
- **docs:** Added `RESEARCH_NOTES.md` with academic basis.
- **license:** Project updated to Apache 2.0.
