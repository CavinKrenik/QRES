# QRES v8.0.0-alpha: Persistent AEON

> **Alpha for eternal swarm persistence and quantum P2P.**

This release introduces **Persistent World Compression** (Phase 4), allowing the Swarm to maintain and synchronize a continuous "World State" across sessions.

## 🚀 Highlights
- **feat(persistence):** Save/Load world states with `--save-state` / `--load-state` CLI flags.
- **feat(swarm):** Distributed state synchronization via GossipSub (Quantum Broadcasting).
- **feat(fidelity):** Automatic fidelity verification ensures >0.98 accuracy during state merges.
- **chore(gui):** Major "Starship" revamp (Tauri v2 + Svelte 5) with D3 graphs.

## ⚠️ Breaking Changes
- **Swarm Protocol:** Incompatible with v7.x discovery key format.
- **Dependencies:** Requires new `libp2p` features in Rust.

## 📦 Assets
- `qres-cli` (Windows/Linux/macOS)
- `qres_quantum_receiver.py` (Updated for v8 protocol)

## 🛠 Upgrade Guide
Nodes must resync their state:
```bash
qres swarm sync --force --peer-id <BOOTSTRAP_NODE>
```
